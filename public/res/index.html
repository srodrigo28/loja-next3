Plataforma de Doações com NextAuth

Uma aplicação full-stack que permite a usuários autenticados realizarem doações, com um dashboard para visualizar o histórico e status dos pagamentos.

Next.js React TypeScript Prisma PostgreSQL Tailwind CSS

O Desafio

Criar um sistema seguro e intuitivo para receber doações, onde a identidade do usuário e o histórico de transações fossem gerenciados de forma eficiente e segura.

Arquitetura e Solução

Utilizamos o Next.js para renderização SSR e otimização de rotas. O NextAuth.js foi integrado para uma autenticação social robusta com o GitHub. O Prisma serviu como nosso ORM para interagir com o banco de dados PostgreSQL, garantindo a tipagem de ponta a ponta.

Entregas por Tela

Tela de Login / Autenticação
  • Integração com o provider do GitHub via NextAuth.js.
  • Callback customizado para normalizar e salvar os dados do perfil do usuário no banco.
  • Gerenciamento de sessão e tokens.
  • Páginas de erro e verificação customizadas.
Dashboard do Usuário
  • Exibição do nome e imagem do usuário logado.
  • Formulário para submissão de novas doações.
  • Lista paginada do histórico de doações (valor, data, status).
  • Atualização do status do pagamento em tempo real (simulado ou via webhook).
