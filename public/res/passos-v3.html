Índice Next-Auth

    Guia: Autenticação com Next-Auth v5, Prisma & GitHub

    Um passo a passo completo para configurar um sistema de autenticação robusto.

    Plataforma de Doações com NextAuth

    Uma aplicação full-stack que permite a usuários autenticados realizarem doações, com um dashboard para visualizar o histórico e status dos pagamentos.

    Next.js React TypeScript Prisma PostgreSQL Tailwind CSS

    O Desafio

    Criar um sistema seguro e intuitivo para receber doações, onde a identidade do usuário e o histórico de transações fossem gerenciados de forma eficiente e segura.

    Arquitetura e Solução

    Utilizamos o Next.js para renderização SSR e otimização de rotas. O NextAuth.js foi integrado para uma autenticação social robusta com o GitHub. O Prisma serviu como nosso ORM para interagir com o banco de dados PostgreSQL, garantindo a tipagem de ponta a ponta.

    Entregas por Tela

    Tela de Login / Autenticação
    • Integração com o provider do GitHub via NextAuth.js.
    • Callback customizado para normalizar e salvar os dados do perfil do usuário no banco.
    • Gerenciamento de sessão e tokens.
    • Páginas de erro e verificação customizadas.
    Dashboard do Usuário
    • Exibição do nome e imagem do usuário logado.
    • Formulário para submissão de novas doações.
    • Lista paginada do histórico de doações (valor, data, status).
    • Atualização do status do pagamento em tempo real (simulado ou via webhook).

    1. Resumo e Tecnologias

    Este guia é um passo a passo completo para implementar um sistema de autenticação robusto em uma aplicação Next.js moderna. O objetivo é integrar um fluxo de login social (GitHub) com um banco de dados PostgreSQL através do Prisma, resultando em uma fundação segura para gerenciar usuários.

    ✨ Principais Tecnologias

    • Framework: Next.js 14+ (App Router)
    • Autenticação: Next-Auth v5 (Auth.js)
    • Banco de Dados: PostgreSQL (ex: Neon, Supabase)
    • ORM: Prisma
    • Provedor de OAuth: GitHub

    🖥️ Telas Resultantes (Exemplo de UI)

    Ao final da implementação deste guia de backend, você terá a fundação para construir as seguintes telas:

    • Página de Login: Uma página que apresentará ao usuário um botão "Entrar com o GitHub".
    • Header Dinâmico: Um cabeçalho que exibe "Login" para visitantes e, para usuários logados, o nome, a imagem e um botão "Sair".
    • Página Protegida: Uma rota (ex: `/dashboard`) que só pode ser acessada por usuários autenticados.

    2. Pré-requisitos

    Antes de começar, garanta que você já tenha:

    1. Um projeto Next.js (App Router) criado.
    2. Uma conta no GitHub.
    3. Um banco de dados PostgreSQL pronto para uso.

    3. Passo 1: Instalar Dependências

    Comece instalando todas as bibliotecas necessárias para o Next-Auth e o Prisma.

    # Instala o Next-Auth v5 (beta)
npm install next-auth@beta

# Instala as bibliotecas do Prisma
npm install @prisma/client @auth/prisma-adapter
npm install prisma --save-dev

    4. Passo 2: Configurar Variáveis de Ambiente

    A segurança da sua aplicação começa aqui.

    1. Gere a Chave Secreta

    npx auth secret

    2. Crie e Configure o Arquivo `.env`

    Na raiz do seu projeto, crie um arquivo .env e adicione as chaves.

    # .env - NÃO ENVIE ESTE ARQUIVO PARA O GITHUB
AUTH_SECRET="COLE_A_CHAVE_GERADA_PELO_COMANDO_AQUI"
DATABASE_URL="SUA_URL_DE_CONEXAO_DO_BANCO_AQUI"
GITHUB_ID="SEU_CLIENT_ID_DO_GITHUB_AQUI"
GITHUB_SECRET="SEU_CLIENT_SECRET_DO_GITHUB_AQUI"

    5. Passo 3: Configurar o App OAuth no GitHub

    Para permitir o login com GitHub, você precisa registrar sua aplicação.

    1. Acesse github.com/settings/applications/new.
    2. Preencha o nome e a URL da sua aplicação.
    3. No campo **"Authorization callback URL"**, use:
    http://localhost:3000/api/auth/callback/github

    Após registrar, o GitHub fornecerá um **Client ID** e um **Client Secret**. Copie e cole-os no seu arquivo `.env`.

    6. Passo 4: Configurar o Código do Next-Auth

    Arquivo de Lógica Principal

    📄 lib/auth.ts

    import NextAuth from 'next-auth';
import GitHub from "next-auth/providers/github";
import { PrismaAdapter } from "@auth/prisma-adapter";
import { prisma } from './prisma';

export const { handlers, signIn, signOut, auth } = NextAuth({
    secret: process.env.AUTH_SECRET,
    adapter: PrismaAdapter(prisma),
    providers: [
        GitHub({
            clientId: process.env.GITHUB_ID,
            clientSecret: process.env.GITHUB_SECRET
        })
    ],
    pages: { signIn: '/auth/signin' }
});

    Rota da API

    📄 app/api/auth/[...nextauth]/route.ts

    import { handlers } from "@/lib/auth";
export const { GET, POST } = handlers;

    7. Passo 5: Configurar o Prisma ORM

    Cliente Prisma Singleton

    📄 lib/prisma.ts

    import { PrismaClient } from "@prisma/client";
const globalForPrisma = globalThis as unknown as { prisma: PrismaClient | undefined };
export const prisma = globalForPrisma.prisma || new PrismaClient();
if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = prisma;

    Schema do Banco de Dados

    Cole o conteúdo abaixo no seu arquivo `prisma/schema.prisma`.

    generator client { provider = "prisma-client-js" }
datasource db { provider = "postgresql", url = env("DATABASE_URL") }

model Account { /* ... schema do adapter ... */ }
model Session { /* ... schema do adapter ... */ }
model User { /* ... schema do adapter ... */ }
model VerificationToken { /* ... schema do adapter ... */ }

// Seu modelo customizado
model Donation {
    id          String        @id @default(cuid())
    amount      Int
    // ... outros campos
    userId      String
    user        User          @relation("userDonations", fields: [userId], references: [id])
}
enum PaymentStatus { PENDING, PAID, FAILED }

    8. Passo 6: Sincronizar o Banco de Dados

    Com o schema pronto, execute os comandos abaixo para formatar, criar a migração e gerar o cliente Prisma.

    # 1. Formata o schema
npx prisma format

# 2. Cria e aplica a migração no banco de dados
npx prisma migrate dev

# 3. Gera o cliente Prisma com base no seu schema
npx prisma generate
