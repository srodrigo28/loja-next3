Índice Next-Auth

    Guia: Autenticação com Next-Auth v5, Prisma & GitHub

    Um passo a passo completo para configurar um sistema de autenticação robusto.

    1. Visão Geral e Pré-requisitos

    Este guia detalha a configuração de um sistema de autenticação em uma aplicação Next.js, utilizando Next-Auth v5, Prisma ORM e o login social com GitHub.

    ✅ Pré-requisitos:

    • Um projeto Next.js (App Router) já criado.
    • Uma conta no GitHub.
    • Um banco de dados PostgreSQL pronto para uso (ex: Neon, Supabase).

    2. Instalação das Dependências

    Começamos instalando todas as bibliotecas necessárias para o Next-Auth e o Prisma.

    # Instala o Next-Auth v5 (beta)
npm install next-auth@beta

# Instala as bibliotecas do Prisma
npm install @prisma/client @auth/prisma-adapter
npm install prisma --save-dev

    3. Configuração das Variáveis de Ambiente

    A segurança da sua aplicação começa com o gerenciamento correto das suas chaves secretas.

    3.1. Gerando a Chave Secreta

    Rode o comando abaixo no seu terminal para gerar uma chave segura para o Next-Auth.

    npx auth secret

    3.2. Configurando o Arquivo `.env`

    Crie um arquivo .env na raiz do projeto e adicione a chave gerada, a URL do seu banco de dados e os placeholders para as chaves do GitHub.

    # .env - NÃO ENVIE ESTE ARQUIVO PARA O GITHUB

# Chave gerada pelo comando 'npx auth secret'
AUTH_SECRET="COLE_A_CHAVE_GERADA_PELO_COMANDO_AQUI"

# URL de conexão do seu banco de dados (ex: do Neon)
DATABASE_URL="postgresql://user:password@host:port/dbname?sslmode=require"
    
# Chaves do GitHub (você obterá no próximo passo)
GITHUB_ID="SEU_CLIENT_ID_DO_GITHUB_AQUI"
GITHUB_SECRET="SEU_CLIENT_SECRET_DO_GITHUB_AQUI"

    4. Configuração do App OAuth no GitHub

    Para permitir o login com GitHub, você precisa registrar sua aplicação.

    1. Acesse a página de registro: github.com/settings/applications/new.
    2. Preencha o nome e a URL da sua aplicação.
    3. No campo **"Authorization callback URL"**, use o valor abaixo para desenvolvimento local:
    http://localhost:3000/api/auth/callback/github

    Após registrar, o GitHub fornecerá um **Client ID** e um **Client Secret**. Copie esses valores e cole-os no seu arquivo `.env`.

    🛡️ AVISO DE SEGURANÇA CRÍTICO

    O `GITHUB_SECRET` é extremamente sensível. Trate-o como uma senha e nunca o exponha publicamente ou em código do lado do cliente.

    5. Configuração Principal do Next-Auth

    Crie o arquivo que conterá a lógica central de autenticação, conectando os provedores e o banco de dados.

    📄 lib/auth.ts

    import NextAuth from 'next-auth';
import GitHub from "next-auth/providers/github";
import { PrismaAdapter } from "@auth/prisma-adapter";
import { prisma } from './prisma';

export const { handlers, signIn, signOut, auth } = NextAuth({
    secret: process.env.AUTH_SECRET,
    adapter: PrismaAdapter(prisma),
    providers: [
        GitHub({
            clientId: process.env.GITHUB_ID,
            clientSecret: process.env.GITHUB_SECRET
        })
    ],
    pages: {
        signIn: '/auth/signin',
    }
});

    Rota da API do Next-Auth

    Crie a rota "catch-all" que irá gerenciar todas as requisições de autenticação.

    📄 app/api/auth/[...nextauth]/route.ts

    import { handlers } from "@/lib/auth";
export const { GET, POST } = handlers;

    6. Configuração do Prisma ORM

    Agora, vamos conectar o Prisma ao nosso banco de dados e definir o schema.

    Cliente Prisma Singleton

    Crie o arquivo `lib/prisma.ts`. Esta é uma boa prática para evitar criar múltiplas conexões com o banco em desenvolvimento.

    import { PrismaClient } from "@prisma/client";

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClient | undefined;
};

export const prisma = globalForPrisma.prisma || new PrismaClient();

if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = prisma;

    Schema do Banco de Dados

    Cole o conteúdo abaixo no seu arquivo `prisma/schema.prisma`. Ele já inclui os modelos do Next-Auth e o modelo customizado `Donation`.

    generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// Modelos Requeridos pelo Next-Auth
model Account { /* ... */ }
model Session { /* ... */ }
model User { /* ... */ }
model VerificationToken { /* ... */ }

// Seu modelo customizado
model Donation {
  id           String        @id @default(cuid())
  amount       Int
  // ... outros campos
  userId       String
  user         User          @relation("userDonations", fields: [userId], references: [id])
}

enum PaymentStatus { PENDING, PAID, FAILED }

    7. Finalizando o Banco de Dados

    Com o schema pronto, vamos aplicar as mudanças no seu banco de dados e gerar o cliente Prisma.

    # Formata o arquivo schema.prisma (boa prática)
npx prisma format

# Cria e aplica a migração no banco de dados
npx prisma migrate dev

# Gera o cliente Prisma com base no seu schema
npx prisma generate

    Verificação

    Para visualizar e interagir com seu banco de dados, use o Prisma Studio:

    npx prisma studio

    Sua aplicação agora está com o backend de autenticação totalmente configurado! O próximo passo é construir os componentes de UI para o login.
