    1.3. Estrutura do Banco de Dados (SQL)

    Execute este script no SQL Editor do Supabase para criar as tabelas e as políticas de segurança.

    -- Tabela para os serviços oferecidos
CREATE TABLE public.services (
  id UUID PRIMARY KEY DEFAULT extensions.uuid_generate_v4(),
  name TEXT NOT NULL,
  description TEXT,
  duration_minutes INT NOT NULL,
  price NUMERIC(10, 2)
);
-- Ativa a segurança em nível de linha (RLS)
ALTER TABLE public.services ENABLE ROW LEVEL SECURITY;
-- Policies (exemplos, ajuste para sua lógica de admin)
CREATE POLICY "Serviços são visíveis para todos." ON public.services FOR SELECT USING (true);
CREATE POLICY "Admins podem gerenciar serviços." ON public.services FOR ALL USING (false); -- Mude para sua lógica de admin

-- Tabela para os horários de atendimento (disponibilidade)
CREATE TABLE public.availabilities (
  id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  day_of_week INT NOT NULL, -- 0=Domingo, 1=Segunda, ..., 6=Sábado
  start_time TIME NOT NULL,
  end_time TIME NOT NULL
);
ALTER TABLE public.availabilities ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Horários são visíveis para todos." ON public.availabilities FOR SELECT USING (true);
CREATE POLICY "Admins podem gerenciar horários." ON public.availabilities FOR ALL USING (false); -- Mude para sua lógica de admin

-- Tabela para os agendamentos
CREATE TABLE public.appointments (
  id UUID PRIMARY KEY DEFAULT extensions.uuid_generate_v4(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  service_id UUID NOT NULL REFERENCES public.services(id) ON DELETE CASCADE,
  start_time TIMESTAMPTZ NOT NULL,
  end_time TIMESTAMPTZ NOT NULL,
  status TEXT DEFAULT 'confirmed' NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE public.appointments ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Usuários podem gerenciar seus próprios agendamentos." ON public.appointments FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Admins podem ver todos os agendamentos." ON public.appointments FOR SELECT USING (false); -- Mude para sua lógica de admin

    2. Bloco 1: Autenticação com Google e Next-Auth

    Configuramos o Next-Auth para usar o Google como provedor de login e o Supabase como banco de dados para armazenar os usuários e sessões.

    2.1. Configuração do Google OAuth

    1. Vá ao Google Cloud Console, crie um projeto e uma "ID do cliente OAuth".
    2. Configure a URI de redirecionamento: `http://localhost:3000/api/auth/callback/google`.
    3. Copie o "ID do cliente" e a "Chave secreta do cliente" para o seu `.env.local`.

    2.2. Lógica do Next-Auth

    📄 lib/auth.ts

    import NextAuth from "next-auth"
import Google from "next-auth/providers/google"
import { SupabaseAdapter } from "@next-auth/supabase-adapter"

// NOTA: Para o Adapter, a chave de serviço (service_role) é necessária para
// contornar as políticas de RLS e gerenciar as tabelas de autenticação.
// Armazene-a com segurança nas variáveis de ambiente do seu servidor.
const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!
const supabaseServiceRoleKey = process.env.SUPABASE_SERVICE_ROLE_KEY!

export const { handlers, signIn, signOut, auth } = NextAuth({
  providers: [
    Google({
      clientId: process.env.GOOGLE_CLIENT_ID,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET,
    }),
  ],
  adapter: SupabaseAdapter({
    url: supabaseUrl,
    secret: supabaseServiceRoleKey,
  }),
  callbacks: {
    async session({ session, user }) {
      // Adiciona o ID do usuário da tabela 'users' para a sessão
      session.user.id = user.id;
      return session;
    },
  },
})

    3. Bloco 2: O Coração - A Página de Agendamento

    Esta é a página principal onde o usuário escolhe a data e o horário. Ela será um Client Component (`'use client'`) para lidar com a interatividade.

    🔄 Ponto de Atenção (Robustez):

    A lógica para buscar os horários disponíveis (`timeSlots`) é a parte mais complexa. Ela deve ser feita no backend (via Server Action ou API Route) e precisa cruzar os dados da tabela `availabilities` com os agendamentos já existentes na tabela `appointments` para um determinado dia.

    📄 app/agendar/page.tsx (Exemplo)

    'use client'

import { useState, useEffect } from "react"
import { Calendar } from "@/components/ui/calendar"
import { Button } from "@/components/ui/button"

export default function AgendarPage() {
  const [date, setDate] = useState(new Date())
  const [timeSlots, setTimeSlots] = useState([])
  const [selectedSlot, setSelectedSlot] = useState('')
  
  useEffect(() => {
    if (date) {
      // LÓGICA PARA BUSCAR HORÁRIOS DISPONÍVEIS NO BACKEND
      // Para este exemplo, usamos dados simulados:
      setTimeSlots(['09:00', '10:00', '11:00', '14:00', '15:00', '16:00'])
    }
  }, [date])

  const handleSchedule = async () => {
    // LÓGICA PARA CHAMAR A SERVER ACTION QUE CRIA O AGENDAMENTO
    // E DEPOIS GERAR E ABRIR O LINK DO WHATSAPP
    const phone = "5562999999999"; // Seu número
    const message = `Olá! Confirmo meu agendamento para ${date?.toLocaleDateString('pt-BR')} às ${selectedSlot}.`;
    const whatsappUrl = `https://wa.me/${phone}?text=${encodeURIComponent(message)}`;
    window.open(whatsappUrl, '_blank');
  }

  return (
    <div className="container mx-auto p-8 grid md:grid-cols-3 gap-8">
      <div className="md:col-span-1">
        <h2 class="text-xl font-bold mb-4">1. Selecione a Data</h2>
        <Calendar mode="single" selected={date} onSelect={setDate} className="rounded-md border" />
      </div>
      <div className="md:col-span-2">
        <h2 class="text-xl font-bold mb-4">2. Selecione o Horário</h2>
        <div className="grid grid-cols-4 gap-2">
          {timeSlots.map(slot => (
            <Button key={slot} variant={selectedSlot === slot ? "default" : "outline"} onClick={() => setSelectedSlot(slot)}>
              {slot}
            </Button>
          ))}
        </div>
        <div className="mt-8">
          <Button onClick={handleSchedule} disabled={!selectedSlot}>
            Confirmar e Notificar via WhatsApp
          </Button>
        </div>
      </div>
    </div>
  )
}

    4. Bloco 3: O Dashboard do Admin

    Esta página (protegida) será um Server Component, buscando os dados dos agendamentos diretamente no servidor para máxima performance e segurança.

    📄 app/dashboard/page.tsx

    import { createServerComponentClient } from '@supabase/auth-helpers-nextjs';
import { cookies } from 'next/headers';
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table";
import { Card, CardHeader, CardTitle, CardContent } from "@/components/ui/card";
import { auth } from '@/lib/auth'; // Importa a sessão do Next-Auth

export default async function DashboardPage() {
  const session = await auth(); // Pega a sessão no servidor
  if (!session?.user) {
    // Redirecionamento ou lógica de acesso negado
    return <p>Acesso negado.</p>;
  }

  const supabase = createServerComponentClient({ cookies });
  
  const { data: appointments } = await supabase
    .from('appointments')
    .select(`*, users(name, email), services(name)`);
    
  return (
    <div className="container mx-auto p-8">
      <h1 className="text-3xl font-bold mb-8">Dashboard de Agendamentos</h1>
      <Card>
        <CardHeader><CardTitle>Próximos Agendamentos</CardTitle></CardHeader>
        <CardContent>
          <Table>
            <TableHeader>
              <TableRow>
                <TableHead>Cliente</TableHead>
                <TableHead>Serviço</TableHead>
                <TableHead>Data e Horário</TableHead>
              </TableRow>
            </TableHeader>
            <TableBody>
              {appointments?.map(app => (
                <TableRow key={app.id}>
                  <TableCell>{app.users.name}</TableCell>
                  <TableCell>{app.services.name}</TableCell>
                  <TableCell>{new Date(app.start_time).toLocaleString('pt-BR')}</TableCell>
                </TableRow>
              ))}
            </TableBody>
          </Table>
        </CardContent>
      </Card>
    </div>
  )
}
